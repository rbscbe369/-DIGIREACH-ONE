# Support

## Need Help?

If you have a question or need support with DIGIREACH ONE, there are several ways you can get help:

### 1. Documentation
Please check our internal documentation and `docs/` folder first. Many common questions and setup instructions are answered there.

### 2. Issue Tracker
If you've encountered a bug or have a feature request, please use our [Issue Tracker](../../issues). Before creating a new issue, please search existing issues to see if your problem has already been reported.

### 3. Community / Team Chat
For general questions, discussions, or if you need immediate assistance, please reach out to the development team on our internal communication channels (e.g., Slack, Microsoft Teams).

### 4. Stack Overflow
For technical questions that are not specific to our internal platform but relate to the technologies we use, consider searching or posting on Stack Overflow.

---
*Note: For security-related issues, please refer to our [SECURITY.md](SECURITY.md) guidelines rather than using public channels.*
